# Public portfolio file selection

| Uploaded item | Decision | Reason |
| --- | --- | --- |
| Source code ZIP | Extract source into the repository | Code should be readable, searchable and rebuildable; a duplicate ZIP adds little |
| Offline HTML | Include a rebuilt `docs/index.html` | Gives reviewers a working recorded demo with repository document links |
| Six-slide PDF | Include | Quick overview for recruiters and hiring managers |
| Product document PDF | Include | Detailed scope, requirements, rules and decision history |
| Impact workbook | Include | Reviewable assumptions and formulas, with known corrections documented |
| Build prompt PDF | Include | Shows how the AI-assisted build was specified |
| Walkthrough video | Include | Quick demonstration without local setup |
| Combined assignment submission PDF | Exclude | Duplicates the slides and write-up and adds assignment packaging |
| Standalone write-up PDF | Replace with a current case study | The case study explains the product and evidence for future employers |
| Interview textbook | Exclude | Personal interview-preparation material, not product evidence |
| Compressed study guide | Exclude | Personal learning material rather than a product deliverable |

The original product document, deck and workbook are explicitly labelled as the original submission record. `LIMITATIONS.md` records subsequent findings, so reviewers can distinguish historical claims from current evidence.
